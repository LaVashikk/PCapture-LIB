# ⚠ PCapture-Lib 4.0 Migration Guide

## 🚨 Critical Breaking Changes

### 1. List Iteration
The standard Squirrel `foreach` loop on a `List` object is **no longer supported** and will throw an error. You must explicitly call `.iter()`.

| Old Code (v3.8) | New Code (v4.0) |
| :--- | :--- |
| `foreach(item in myList) { ... }` | `foreach(item in myList.iter()) { ... }` |

### 2. TracePlus "Note" Parameter Removed
The `note` parameter has been removed from all `TracePlus` functions and filters to reduce memory overhead.
**Workaround:** If you previously used `note` to pass context to filters, use **global scope variables** (`::globalVar <- ...`) or bound functions instead.

| Old Code (v3.8) | New Code (v4.0) |
| :--- | :--- |
| `TracePlus.Bbox(start, end, null, settings, "debug_context")` | `::debug_ctx <- "context"; TracePlus.Bbox(start, end, null, settings)` |
| `ApplyCollisionFilter(ent, note)` | `ApplyCollisionFilter(ent)` |
| `result.GetNote()` | *Removed* |

## 🔄 API Renaming & Replacements

### 🧩 General / Macros / Math
Standardization to `IsEqual` and casing fixes.

| Class / Module | Old Name | New Name | Notes |
| :--- | :--- | :--- | :--- |
| `macros` | `isEqually(a, b)` | **`IsEqual(a, b)`** | Checks types internally |
| `math.vector` | `isEqually(a, b)` | *Removed* | Use `IsEqual` (approximate) |
| `math.vector` | `isEqually2(a, b, prec)` | **`IsEqual(a, b, prec)`** | Default precision: 1000 |
| `pcapEntity` | `isEqually(other)` | **`IsEqual(other)`** | |
| `Quaternion` | `isEqually(other)` | **`IsEqual(other)`** | |
| `Matrix` | `isEqually(other)` | **`IsEqual(other)`** | |

### 📦 pcapEntity (Entity Library)
Methods have been renamed to follow PascalCase or renamed for clarity.

| Old Name | New Name | Notes |
| :--- | :--- | :--- |
| `SetAbsAngles(vec)` | **`SetAngles2(vec)`** | Accepts a **Vector** input instead of `(x, y, z)`. |
| `SetAbsOrigin(vec)` | **`SetAbsOriginNative(vec)`** | **Native Engine Call.** Use this if you need the standard behavior (has client interpolation, works better with attachment parents). |
| `SetAbsOrigin2(vec)` | **`SetAbsOrigin(vec)`** | **Teleport Logic.** This custom function is now the default. It bypasses client-side interpolation (instant move). |
| `getBBoxPoints()` | **`GetBBoxPoints()`** | |
| `getBBoxFaces()` | **`GetBBoxFaces()`** | |
| `GetAllChildrenRecursivly()` | **`GetAllChildrenRecursively()`** | Typo fix |

### 🗓 ActionScheduler
Cleanup of unsafe or redundant methods.

| Old Name | New Name | Notes |
| :--- | :--- | :--- |
| `CancelAll()` | `CancelAll()` | **Changed Behavior:** No longer clears "global" events. |
| *N/A* | **`UNSAFE_ClearWithGlobal()`** | Use this to strictly clear everything including global. |
| `CancelByAction(func)` | *Removed* | Save the event name and use `Cancel(name)` instead. |

### 🔍 TracePlus
Significant refactoring of the internal analyzer.

| Old Name | New Name | Notes |
| :--- | :--- | :--- |
| `TraceLineAnalyzer` | **`BboxTraceAnalyzer`** | Internal class renamed. |
| `result.GetHitpos()` | **`result.GetHitPos()`** | Capitalized 'P'. |
| `CalculateImpactNormalFromBbox2` | *Removed* | Logic merged or deprecated. |

## ❌ Removed Features

*   **`pcapEntity.GetBBox()`**: Removed. Use `GetBoundingMins()` and `GetBoundingMaxs()` directly or `GetAABB()`.
*   **`pcapEntity.GetParent()`**: Removed. Use standard API `CBaseEntity.GetMoveParent()` or `GetUserData("parent")` if manually set.
*   **`pcapEntity.SetBBox(string, string)`**: String support removed. Arguments must now be `Vector`.
*   **`ScheduleEvent.AddInterval`**: Now throws an error if `interval <= 0`.
*   **`TracePlus.Settings`**: Removed `note` argument from filter callbacks.

---

## 🛠 Behavioral & Internal Changes

1.  **Strict Argument Typing**:
    *   `ArrayEx.FromArray(arr)` now throws if `arr` is not a raw array.
    *   `ScheduleAction` throws if arguments are not an array or null.
    *   `entLib` creators (`CreateByClassname`, `CreateProp`) now throw explicit errors on invalid arguments.
    *   `math.min` / `math.max` throw if called with no arguments.

2.  **TracePlus Optimization**:
    *   The `BboxTraceAnalyzer` has been rewritten using an analytical "slab method" for AABB intersection. It is significantly faster but might behave slightly differently in edge cases.
    *   **Legacy Mode:** If you need the old behavior, set `::USE_LEGACY_BBOXCAST_ANALYZER = true`.

3.  **List Implementation**:
    *   Internal nodes `prev_ref`/`next_ref` renamed to `_prevRef`/`_nextRef` to discourage direct access.
    *   `SwapNode` Capitalization fix.

4.  **Entity Caching**:
    *   `GetBoundingCenter` no longer caches the result in UserData; it calculates it fresh every time for accuracy.
